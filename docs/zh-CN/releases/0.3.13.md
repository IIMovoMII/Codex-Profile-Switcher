## Codex Profile Switcher 0.3.13

修复 Codex 已安装却被误报为找不到 `codex.exe` 的问题，并补齐从旧实现迁移时遗漏的位置兼容。

### 自动查找与诊断

- 恢复 Codex Desktop 的 `%LOCALAPPDATA%\OpenAI\Codex\bin\<版本>\codex.exe`、bin 根目录和 `CODEX_CLI_PATH` 支持；继续查找 PATH、npm 原生 CLI 和已知 Programs/Codex 目录。
- 每次重新解析 Desktop 版本目录，避免更新后继续使用失效路径；显式指定的路径失效时明确报错，不悄悄改用另一个安装。
- 环境检查与切换使用同一个查找器，显示真实命令路径。本地 `--version` 检查无需登录，文件已找到但无法运行、权限不足和候选位置未找到分别显示。
- 读取失败不再统一当成文件缺失；位置记录被占用时保留原件并提示，避免按新安装创建空数据目录。手动模型目录读取失败时显示不可用，不误显示为空目录。

### 旧数据与格式边界

- 恢复 `RelayModelCatalogPath`、`MonitorDataDir` 及对应连字符参数；账号自定义模型路径仍优先，仅通过已有维护标记与独立助手协调。
- 历史库识别恢复覆盖 Codex 目录及 sqlite 子目录中的分页投影表；发现其他版本项目库时提示格式边界，不报成数据库缺失。
- 如果历史 JSONL 改写涉及尚未适配的分页投影偏移，在写入前停止并保留数据；不会猜测新格式或静默跳过关联库。
- 保留账号、模型目录、聊天、项目、固定入口和自包含运行时。切换核验失败仍恢复认证、配置和活动账号指针，已完成的独立历史准备继续保留。

应用内公告与 GitHub Release 使用本文件。验证使用临时目录、合成账号和模拟 CLI，不执行真实账号切换、登录或 API 请求，也不等同于跨机器验证。
