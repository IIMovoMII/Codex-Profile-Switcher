## Codex Profile Switcher 0.3.15

修复部分子代理历史带有父会话继承前缀时，0.3.14 提示“同一历史文件含有不同会话身份”并阻断普通账号切换的问题。

### 子代理历史兼容

- 识别已核验的分页子代理继承结构：首条元数据仍决定本地会话与物理投影，前缀里的父会话元数据不再误判为当前文件的另一身份。
- 同时核对父会话、派生来源、共同 session_id、子代理来源、继承边界和连续 ordinal。边界之后混入父会话事件、来源冲突、缺失或异常边界仍在写入前停止。
- 父会话元数据中的 history_base 仅作为继承内容保留，不套用当前子代理的游标，也不据此更新父会话数据库。数据库 provider 只关联有本地历史文件的实际会话。
- 延续已有 provider 与模型输入标识的转换规则，同步当前文件的分页游标和轮次字节偏移。原生界面 ID、文字、ordinal、继承关系、未知字段及无关数据库行保留；复制来的前缀事件不能冒充子代理界面项目的来源。
- 同时核对普通 rollout 文件名和分段文件名的身份。升级后重新检查旧历史就绪缓存；恢复清单继续兼容版本 2、3，保留备份与外部修改保护。

历史准备和后续账号认证仍为独立事务。故障、取消与重启恢复的处理方式不变；未知继承格式仍明确停止，不能保证所有未来 Codex 格式自动兼容。

本版验证使用临时目录、合成历史、合成账号与模拟运行接口；本机现有历史仅作只读规划核对，没有执行真实账号切换、OAuth 登录或 Codex API 请求，不等同于跨机器验证。
