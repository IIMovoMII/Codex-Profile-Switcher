## Codex Profile Switcher 0.3.16

修复安装成功后，桌面入口仍提示“找不到切换器程序”的问题，并保留 0.3.15 的子代理继承历史兼容修复。

### 安装与启动

- 固定入口现在正确处理安装路径文件末尾的 CRLF、LF、制表符和 BOM，继续支持中文路径、UTF-8/UTF-16、兼容入口和源码发布指针。含有多条非空路径的文件仍拒绝猜测。
- 已知 0.3.7–0.3.15 旧入口先备份为 `.legacy-0.3.15.bak`，再更新为修复版；用户修改过的未知入口继续保留并提示。
- 升级清理由构建时明确列出的旧版公告及 SHA-256 决定：只移除字节一致的旧说明，修改过的说明、未知文件、目录链接和运行数据保留。同名程序文件继续由新载荷覆盖。
- 安装验收新增通过真实固定入口启动和关闭 WPF，使用安装器实际生成的 BOM/CRLF 路径文件，同时覆盖旧入口升级、版本登记、旧公告清理与用户额外文件保护。

### 历史兼容

延续 0.3.15 对分页子代理父会话继承前缀的核验和投影映射。真正的会话身份冲突、未知继承结构及读取后变化的历史仍停止写入；实际切换前仍需退出 Codex。

本轮自动化验证使用隔离目录与合成数据；本机维护可在备份后更新已安装程序并验收桌面入口，不替用户执行真实账号切换、OAuth 登录或 Codex API 请求。应用内公告与本文件同源。
