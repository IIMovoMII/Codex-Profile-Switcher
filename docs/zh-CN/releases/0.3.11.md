## Codex Profile Switcher 0.3.11

本次稳定版包含 0.3.8–0.3.11 的界面、更新、存储和公告改进，本地 0.3.10 也可检测并更新到此版本。

### 新界面与模型设置

- 采用青绿色侧栏、账号卡片和右侧设置面板；账号管理、诊断与维护、操作记录、设置与更新各有独立入口。
- 账号卡片可直接切换或打开模型设置；支持搜索、官方/API 筛选、编辑、重新应用、重新授权和删除。
- 模型可从实际本地目录选择或填写 ID；API 账号分别使用手动目录或指定官方账号的独立快照，显示路径、来源和更新时间。

### 更新与公告

- GitHub API 限流时自动回退官方 Release 页面，连接失败有限重试，检查限时 25 秒并显示原因。
- 应用内公告与 GitHub Release 使用同一份版本说明；离线可查看当前版本公告，公告加载失败不影响版本检查。
- 下载后校验 SHA-256，由用户确认后安装；保留启动时自动检查更新开关。

### 数据目录与存储

- 自动使用默认数据目录、现有 CODEX_HOME 和有效的已记住位置；位置失效才提供手动选择，不自动移动账号或聊天。
- 无历史变化时不创建空备份。已完成历史/项目备份每类最多保留 3 份，按 14 天和合计 256 MB 清理旧材料，每类至少保留最新 1 份；待恢复、未知材料及用户额外文件受保护。
- 更新安装包保留最近 1 个；未完成下载和已知旧检查缓存超过 24 小时清理。账号、手动模型目录和官方缓存不在清理范围内。

### 安装与兼容

- 提高压缩率并移除其他语言附加资源，保留简体中文、内置英文和完整 .NET 10/WPF 运行时；安装后可直接使用，无需另装 SDK 或运行时。
- 安装和卸载使用简体中文；桌面快捷方式继续使用固定入口，已知旧入口先备份再升级，用户修改的入口保留。
- 沿用已有档案和 DPAPI 凭据格式；升级及卸载保留账号、模型目录、聊天和项目。安装或切换前请完全退出 Codex。

已通过隔离行为测试、WPF 界面和安装验证；不将这些结果等同于真实账号或跨机器试用。当前面向 Windows 10/11 x64，使用 MIT 许可证。
