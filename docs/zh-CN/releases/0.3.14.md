## Codex Profile Switcher 0.3.14

修复 0.3.13 遇到已存在的分页历史投影库时，因缺少偏移适配而阻断普通账号切换的问题。此次补齐正式 C# 适配，同时保留写入前检查和失败恢复。

### 分页历史兼容

- JSONL 的 provider 变化会同步更新分页游标、轮次起止字节偏移和分段继承边界；兼容独立投影库、合并库及旧轮次表的可选字段。
- 原生界面项目 ID、聊天文字、item_json、ordinal、未知字段和无关线程保持原样；仅处理已有规则允许的模型输入标识与 provider，不重新生成聊天。
- 区分逻辑会话与物理分段的投影身份，支持已核验的本地父段继承；来源冲突、循环、异常游标、未知偏移字段或无法核验的界面来源在写入前停止，不冒充文件缺失。

### 同类问题修复

- 修复 UTF-8 字节位置被当成 C# 字符索引的问题，避免中文或 emoji 位于 provider 之前时改错字段；保留 BOM、空白行、换行与末尾无换行的布局。
- 历史增量指纹纳入 SQLite WAL，避免数据库主文件未变就漏掉新提交；即使文件总长度不变，也逐记录检查偏移变化。
- 新恢复记录覆盖 JSONL 和关联数据库投影；部分写入、提交后失败及取消可回退，重启时可核对并完成或恢复。恢复前检查全部来源，外部修改存在时保留材料并停止覆盖。
- 新版已完成历史备份继续沿用每类最多 3 份的保留规则，未完成或待恢复材料保留。快速切换仍沿用跳过历史处理的约定。

历史准备与后续认证切换保持独立：历史已整理完成后，若账号核验失败，认证和配置恢复，已完成的历史及其备份保留。遇到尚未支持的 Codex 格式时仍会明确提示，不能保证未来格式无需适配。

应用内公告与 GitHub Release 使用本文件。验证使用临时目录、合成分页历史、合成账号及模拟运行接口；未执行真实账号切换、OAuth 登录或 Codex API 请求，不等同于跨机器验证。
