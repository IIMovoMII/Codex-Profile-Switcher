## Codex Profile Switcher 0.3.12

本次更新修复 SQLite 依赖安全告警，并清理仓库中退出使用的旧实现。

### 安全与维护

- 更新 Microsoft.Data.Sqlite 及其原生 SQLite 依赖，修复 GHSA-2m69-gcr7-jv3q 涉及的内存损坏漏洞。
- CI 审计直接和传递依赖，发现已知漏洞时停止构建；更新使用 Node 24 的 GitHub Action，并固定其提交版本。
- 移除旧 PowerShell 应用、旧对照测试及无用开发材料，保留当前 C# 行为回归、构建和隔离安装验证。
- 修复 CMD 入口可能把失败退出码报告为成功的问题，保留参数传递、单次按键等待及自动化跳过等待。

### 升级与兼容

- 保留账号管理、模型目录、聊天共享、恢复、更新与全部现有界面功能；旧档案及固定启动入口继续兼容。
- 应用内公告与本页使用同一份版本说明。Windows x64 安装包仍携带完整 .NET 10/WPF 运行时，无需另装运行时。
- 升级或切换前请完全退出 Codex；安装和卸载保留账号、手动模型目录、聊天与项目。

验证仅使用隔离目录和合成数据，不等同于真实账号或跨机器试用。
